# Contributing

Thanks for wanting to improve this project. Keep it simple.

---

## How to contribute

### 1. Fork the repository

Click **Fork** on GitHub to create your own copy.

### 2. Clone your fork

```bash
git clone https://github.com/<your-username>/todos.git
cd todos
```

### 3. Create a branch

```bash
git checkout -b feature/your-change
```

### 4. Make your changes

- Only update what is needed.
- Do not change the `todo.json` schema (see `prompt.md`).
- Keep the app lightweight — HTML, CSS, and vanilla JavaScript only.

### 5. Test locally

Right-click `index.html` → **Open with Live Server** in VS Code.

### 6. Commit and push

```bash
git add .
git commit -m "describe your change"
git push origin feature/your-change
```

### 7. Open a Pull Request

Go to your fork on GitHub and click **Compare & pull request**.

---

## What we welcome

- Bug fixes
- Small UI improvements
- Better accessibility
- Documentation fixes

## What to avoid

- Adding frameworks or build steps
- Adding a backend, database, or login
- Changing the folder structure
- Breaking the `todo.json` format
